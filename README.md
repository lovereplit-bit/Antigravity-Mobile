### Обзор

**Antigravity Mobile** приносит автономную агентную разработку прямо на телефон.

Без PRoot, chroot и виртуализации: приложение работает **нативно в пользовательском пространстве Android (Bionic)** и использует полную скорость накопителя и физические ядра процессора. Агент на базе моделей Gemini изучает репозитории, пишет код в нескольких файлах, собирает бинарники и запускает тесты прямо на устройстве.

Интерфейс полностью на русском языке.

---

### Возможности

* **Автономный агент:** планирует задачи, правит код по всему дереву проекта, запускает консольные инструменты и исправляет ошибки сборки.
* **Расширенный доступ (Shizuku):** операции уровня ADB (`uid=2000`) без root: установка пакетов, диагностика системы.
* **Встроенный менеджер пакетов `pkg`:** быстрая установка сред разработки (`git`, `python`, `node`, `clang`) из репозиториев Termux.
* **Адаптивный интерфейс:** сенсорный мобильный вид и опциональный режим рабочего стола для планшетов, клавиатур и Samsung DeX.
* **Устойчивый стрим:** автоматическое переподключение после сворачивания приложения и кратких обрывов сети.
* **Поддержка ARMv8.0-A:** прозрачная эмуляция атомарных и SIMD-инструкций (`liblse_compat.so`) для старых процессоров.
* **Фоновый микро-демон:** `agy-daemon` (менее 10 МБ ОЗУ) с планировщиком cron, наблюдателем файлов и очередью задач ИИ.
* **Обновление на месте:** постоянный ключ подписи позволяет обновлять APK без потери сессий и рабочих данных.

### Быстрый старт

1. Скачайте APK из раздела релизов и установите его:
   * `antigravity.apk` — стандартная сборка.
   * `antigravity-region-bypass.apk` — сборка с обходом региональной проверки аккаунта (нужен VPN или сетевой туннель).
2. Выдайте доступ к файлам (**Доступ ко всем файлам**). По желанию включите Shizuku.
3. Установите нужные среды выполнения в терминале или попросите агента:
   ```bash
   pkg update && pkg install git python nodejs
   ```

### Сборка и тесты

```bash
# Стандартная сборка (dist/antigravity.apk):
bash build.sh

# Сборка с обходом региона (dist/antigravity-region-bypass.apk):
bash build.sh --region-bypass

# Все тесты модулей:
bash test_all_modules.sh
```

### Структура репозитория

```text
antigravity/
├── config/             # Константы приложения, пути окружения и правила ИИ
├── modules/            # Независимые модули ядра
│   ├── core/           # Распаковка бинарников, загрузчик glibc, шимы, манифест SHA-256
│   ├── patches/        # Движок бинарных патчей (эмуляция syscall, resolv, SIGILL)
│   ├── io/             # Шина ввода-вывода: брокер событий, FIFO, сокеты
│   ├── env/            # Резолвер путей, диагностика, журнал, CLI
│   ├── builder/        # Сборщик APK без Gradle (javac, D8, aapt, zipalign, apksigner)
│   └── runner/         # Подготовка рантайма, проверка порта, E2E-тесты
├── app/                # Android-оболочка (сплэш, WebView, системные мосты)
├── web/                # Локальный веб-интерфейс, русская локализация, темы
├── env/                # Пользовательское окружение Bionic, оверлей Termux, pkg
├── docs/assets/        # Логотип
├── build.sh            # Корневой скрипт сборки APK
└── test_all_modules.sh # Тесты всех модулей
```

> [!TIP]
> В каждом из каталогов `modules/`, `app/`, `web/` и `env/` есть собственный `README.md` с подробной технической документацией.
