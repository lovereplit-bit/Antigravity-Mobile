# Antigravity Mobile 1.0.0

Первый релиз.

## Что внутри

* Полностью русифицированный интерфейс: экран входа, настройки, выбор модели, чат, терминал, файлы, уведомления и системные сообщения оболочки.
* Новая иконка приложения (радужная арка), единая для лаунчера, сплэша, уведомлений и веб-интерфейса.
* Автоматическое переподключение стрима после возврата из фона и при смене сети (Wi-Fi и мобильные данные, VPN): повторные попытки до 60 секунд без перезапуска приложения и без повтора задачи.
* Исправлена вёрстка окна авторизации в портретной ориентации: рамки больше не выходят за поля экрана.
* Исправлена работа модели Gemini Flash в сборке с обходом региона.
